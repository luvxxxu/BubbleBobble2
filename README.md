# Bubble Bobble C11 / Raylib

[JulianRijken/BubbleBobble](https://github.com/JulianRijken/BubbleBobble)의 커밋 `6a59ee99e621f4061cab50802155b9c28c51c4f9`를 바탕으로 만든 C11 포트입니다. Raylib 5.5로 화면, 키보드·게임패드 입력과 소리를 처리합니다. 현재는 1인 또는 2인이 함께 몬스터를 거품에 가두고 터뜨려 다섯 라운드를 진행하는 게임입니다. [참고 저장소 main](https://github.com/luvxxxu/BubbleBobble/tree/5ea63987d393d9f3c811a5b129f453d08e599bd0)의 게임 규칙을 현재의 단순한 C 함수와 배열 구조로 복원했습니다.

## 플레이

- 메뉴에서 위/아래로 1인, 2인 또는 순위표를 고르고 Enter로 선택합니다. 숫자 1/2로 인원을 바로 선택할 수도 있습니다.
- 1P는 초록 캐릭터, 2P는 파랑 캐릭터입니다. 2P의 발사·포획·파열·부활 버블도 파란색으로 표시합니다. 같은 키보드 또는 게임패드 두 개로 함께 플레이할 수 있습니다.
- 서로 다른 다섯 라운드에 각각 공중 발판 다섯 개, 측면 벽과 바닥 순환 통로가 있습니다. 각 공중 발판은 라운드 시작 시 초당 1.5 이상 3 미만 타일의 속도와 시작 위치·방향을 무작위로 정하므로 처음부터 제각각 왔다 갔다 합니다. 기본 화면에서는 원래 위치에서 좌우 한 타일씩 왕복하고, 전체 화면 등으로 맵 폭이 넓어지면 추가 폭의 절반만큼 왕복 범위도 늘어납니다. 발판 전체가 양옆 벽 안에 남도록 실제 범위를 제한합니다. 한 발판을 이루는 블록들은 함께 움직입니다. 위에 선 플레이어·몬스터·음식도 해당 발판과 함께 이동하고, 점프하면 발판에서 떨어집니다. 맨 아래 바닥과 양옆 벽은 고정됩니다.
- 공중 발판은 라운드에 따라 정해진 시간 동안 유지된 뒤 점선 테두리가 세 번 깜빡이고 사라집니다. 3초 뒤 같은 점선 예고를 거쳐 다시 생깁니다. 예고는 0.2초 표시·0.2초 숨김을 세 번 반복하는 1.2초이며, 소멸 예고가 끝나기까지는 밟을 수 있고 생성 예고 중에는 통과합니다. 사라진 발판 위의 물체는 즉시 떨어집니다. 발판의 좌우 이동은 이 주기 동안 계속되고, 일시 정지 시 이동과 주기가 함께 멈춥니다.
- 각 플레이어에게 별도의 마나, 점수, 생명 5개, 발사 대기 시간과 이동 상태가 있습니다.

| 동작 | 1P | 2P |
|---|---|---|
| 이동 | A / D | 왼쪽 / 오른쪽 방향키 |
| 점프 | W | 위쪽 방향키 |
| 거품 발사 | E | **Space** |
| 게임패드 | 첫 번째 패드 | 두 번째 패드 |

게임패드는 왼쪽 스틱 또는 D-pad로 이동하고, 동쪽 버튼 또는 D-pad 위로 점프하며, 남쪽 버튼으로 거품을 발사합니다. 1인 모드에서는 방향키와 X(점프), Space·Slash·Right Ctrl(발사)도 1P를 조작합니다. 2인 모드의 Slash와 Right Ctrl은 발사에 사용하지 않습니다. 두 캐릭터는 서로를 밀지 않으며, 누구나 떠 있는 거품에 올라타거나 빠르게 부딪쳐 터뜨릴 수 있습니다.

- 인트로에서 Enter로 바로 시작합니다.
- P 또는 게임패드 Start로 일시 정지하거나 재개합니다. 창 포커스를 잃어도 게임 시간이 멈춥니다.
- Escape로 메뉴에 돌아갑니다. 메뉴에서 다시 누르면 종료합니다.
- M은 음소거, F11은 전체 화면 전환입니다.
- 창 크기와 Retina 배율을 반영한 실제 해상도로 화면을 그립니다. 캐릭터·타일·글자는 가로·세로에 같은 배율을 적용하고, 넓어진 화면만큼 실제 이동 가능한 맵 영역을 확장합니다. 벽과 바닥은 새 경계에 맞춰 이어지며, 점수·마나(위)와 목숨·라운드(아래)는 맵 밖의 검은 띠에 그려서 맵을 가리지 않습니다. 기본 창은 768×672이며, 정수 배율이 창을 85%도 못 채울 때는 소수 배율로 꽉 채웁니다. 메뉴·점수 화면도 창 높이에 맞춰 커집니다. 창을 다시 줄여도 라운드·점수·마나·발판 속도는 유지합니다. F11은 모니터의 현재 해상도를 유지하는 테두리 없는 전체 화면으로 전환합니다.

공중 발판은 중앙과 바닥을 기준으로 배치해 기존 시작 위치와 높이 간격을 유지합니다. 화면 축소로 이동 범위가 줄면 발판과 그 위의 탑승자를 함께 새 범위 안으로 옮깁니다. 맵은 가로·세로 각각 최대 256타일까지 확장하며, 이 한도를 넘는 극단적인 창 비율에서는 바깥 벽을 더 그려 게임 영역이 잘리지 않게 합니다.

발판 소멸은 다음 표에 따라 점진적으로 빨라집니다. 유지 시간이 지난 발판 중에서 매번 무작위로 하나를 고르며, 고정된 순서로 돌아가지 않습니다. 소멸 예고 시작은 라운드별 간격으로 엇갈립니다. 재생성까지 끝나야 다음 발판에 자리를 넘기므로 한꺼번에 모두 사라지지 않고 항상 최소 두 개는 정상 표시됩니다.

| 라운드 | 소멸 예고 전 최소 유지 시간 | 다음 발판 소멸 예고까지 최소 간격 | 동시에 예고·부재 상태일 수 있는 발판 |
|---|---|---|---|
| 1 | 20~22초 | 8초 | 1개 |
| 2 | 16.5~18.5초 | 6.5초 | 1개 |
| 3 | 13~15초 | 5초 | 2개 |
| 4 | 9.5~11.5초 | 3.5초 | 2개 |
| 5 | 6~8초 | 2초 | 3개 |

## 몬스터와 라운드

총 다섯 라운드에 기본 화면 폭에서는 몬스터가 1·2·3·4·5마리씩 등장합니다. 넓은 화면에서는 `올림(기본 마릿수 × 현재 맵 폭 / 32)`마리로 늘어납니다. 예를 들어 폭이 두 배면 2·4·6·8·10마리입니다. 플레이 중 화면을 넓혀도 추가분이 즉시 등장 절차에 들어갑니다. 화면을 줄여도 기존 적은 사라지지 않으며, 같은 폭으로 다시 넓혀도 이미 처치한 적을 되살리지 않습니다. 클리어 대기 중에는 적을 추가하지 않고 다음 라운드에 새 폭을 적용합니다.

- **ZenChan:** 플레이어를 향해 걷고 발판으로 점프합니다. 거품에서 탈출하면 더 빨라집니다.
- **Maita:** 플레이어를 따라 움직이며 바위를 던집니다. 바위도 피해야 합니다.
- **Monsta:** 주기적으로 도약하고 공중에서도 전진합니다.

거품에 닿은 몬스터는 포획됩니다. 빈 거품은 발사 후 8초가 지나면 저절로 터지지만, 몬스터를 포획하면 남은 수명에 5초가 추가되어 발사 후 13초까지 유지됩니다. 포획 시 발사 타이머를 초기화하지는 않습니다. 시간이 지나 거품이 저절로 터지면 몬스터가 탈출하므로, 플레이어가 빠르게 부딪쳐 터뜨려 처치해야 합니다. 쓰러진 몬스터는 그 자리에서 살짝 떠올랐다가 바닥으로 떨어지고, 바닥에 닿으면 음식으로 바뀝니다. 음식은 먼저 먹은 플레이어 한 명에게만 점수를 줍니다. 20종 음식의 드롭 순서를 섞어 한 묶음 안에서 중복되지 않게 하며, 순서는 다음 라운드에도 이어집니다.

모든 음식은 한 개당 300점입니다. 한 라운드의 음식을 모두 먹으면 마지막 음식을 먹은 플레이어에게 보너스 500점을 한 번 지급하고, 화면 가운데에 `ALL FOOD BONUS!`와 `P1  +500`(2P는 `P2`)을 3초 동안 표시합니다. 2인 모드에서는 두 사람이 먹은 개수를 합산합니다. 화면 확장으로 추가된 몬스터의 음식도 포함하며, 먹지 못하고 사라진 음식이 있으면 보너스를 받을 수 없습니다.

몬스터나 바위에 맞으면 생명이 하나 줄어듭니다. 생명이 남아 있으면 1.5초 뒤 자기 시작 위치에서 부활하고 3초 동안 무적입니다. 1인 모드는 생명이 0이면 탈락합니다. 2인 모드에서는 모든 생명을 소진한 플레이어가 사망 연출 후 큰 부활 버블로 나타납니다. 버블은 동료를 추적하지 않고 1~1.8초마다 무작위로 방향과 속도를 바꾸며 둥둥 떠다닙니다. 화면 가장자리에서는 안쪽으로 되돌아오고, 공중 발판에 걸리지 않습니다.

부활 버블이 생성된 뒤 **10초 안에** 살아 있는 동료가 닿거나 빈 거품을 쏘아 터뜨리면 그 자리에서 생명 1개와 3초 무적으로 돌아옵니다. `HELP 10S`처럼 남은 구조 시간을 표시합니다. 10초가 지나면 버블은 사라지고 `NEXT ROUND` 대기로 바뀌어 그 라운드에서는 구조할 수 없습니다. 동료가 라운드를 클리어하면 다음 라운드 시작 위치에서 생명 1개와 3초 무적으로 자동 부활합니다. 점수와 마나는 보존합니다. 아직 제한 시간이 남은 버블은 라운드 전환이나 화면 크기 변경으로 시간을 초기화하지 않습니다. 두 플레이어 모두 생명을 소진하면 사망 연출 뒤 게임 오버입니다.

포획 중인 적도 남은 적으로 세며, 모두 처치하면 몬스터가 날아가 벽과 바닥에 튕기다가 과일이 되고, 과일이 떨어진 뒤 5초를 기다렸다가 화면이 위로 올라가며 다음 라운드로 넘어갑니다. 마지막 라운드까지 마치면 승리합니다.

## 순위표

승리 또는 게임 오버 뒤 참여한 플레이어별로 이니셜 세 글자를 입력합니다. 위/아래는 글자 선택, 왼쪽/오른쪽은 위치 선택, Enter는 다음 글자 또는 저장입니다. A–Z를 직접 입력할 수도 있습니다. 점수가 0이거나 먼저 탈락했더라도 각 플레이어의 기록을 따로 입력할 수 있습니다. Escape는 아직 확정하지 않은 입력을 취소하고 메뉴로 돌아갑니다.

상위 10개 기록은 실행 파일 옆의 `Scores.txt`에 저장합니다. 한 줄에 `점수 라운드 이름` 형식(예: `20000 1 JUL`)이라 메모장으로도 열어 볼 수 있습니다. 메뉴의 순위표에서 다시 확인할 수 있으며 저장에 실패하면 화면에 표시하고 다시 시도할 수 있습니다.

## 플레이어별 마나

마나는 새 게임에서 두 플레이어 모두 0으로 시작합니다. 플레이 중 각자 다음 주기를 자동으로 반복합니다.

1. 15초 동안 0%에서 100%까지 충전합니다.
2. 가득 차면 5초 동안 좌우 이동 속도가 두 배가 됩니다. `X2`와 남은 시간이 표시됩니다.
3. 마나가 0이 되면 원래 속도로 돌아가고 다시 충전합니다.

점프 높이와 낙하 속도는 바뀌지 않습니다. 기본 좌우 속도는 지상 6타일/초, 공중 제어 시 3타일/초이며 플레이어에게만 `현재 맵 폭 / 32`를 곱합니다. 폭이 두 배면 좌우 속도도 두 배가 되고, 마나 가속 중에는 여기에 다시 두 배를 적용합니다. 화면 크기를 바꾸는 순간 공중 관성에도 같은 폭 변화율을 반영합니다. 몬스터·발판·투사체의 속도는 화면 폭에 따라 바뀌지 않습니다. 메뉴·인트로·결과 화면·사망 대기·구조 대기·탈락·일시 정지·창 포커스 상실 중에는 마나가 진행되지 않습니다. 부활이나 다음 라운드에서는 남은 마나를 유지하며, 새 게임에서만 초기화합니다. 1인 모드에서는 2P의 입력과 마나를 갱신하지 않습니다. 두 플레이어가 동시에 시작하므로 보통 게이지는 같은 비율로 보이지만, 저장 값과 계산은 각각 독립적입니다.

## 빌드 및 실행

C 컴파일러와 CMake만 있으면 됩니다. 처음 빌드할 때 raylib 5.5를 내려받습니다. 자세한 내용은 [빌드 안내](docs/BUILD.md)에 있습니다.

### macOS ARM / Apple Silicon

```sh
./scripts/build-macos.sh
./build/macos-arm64/bin/BubbleBobble
```

Finder에서 실행할 로컬 앱은 `./scripts/package-macos.sh`로 만듭니다. 자세한 내용은 [macOS 앱 패키징](docs/MACOS_APP.md)을 보세요.

### Windows x64 / Visual Studio 2026

```powershell
./scripts/build-windows.ps1
./build/windows-x64/bin/Release/BubbleBobble.exe
```

실행 파일 옆의 `assets` 폴더(그림·소리)는 빌드할 때 자동으로 복사됩니다. 실행 파일을 옮기면 `assets` 폴더도 함께 옮기세요.

## 코드를 읽는 순서

게임 로직은 고정 크기 배열, 간단한 구조체, 일반 함수와 `if`·`for` 중심으로 작성했습니다. 파일은 기능별로 11개이고, 한 파일은 대략 300~500줄입니다.

`game->players[0]`은 게임 구조체 안의 첫 번째 플레이어입니다. `&`는 데이터의 주소를 전달하고, `->`는 그 주소에 있는 구조체의 항목을 읽거나 바꿉니다. `dt`는 이번 갱신에서 흐른 초이며, `속도 × dt`가 이번에 이동할 거리입니다. `memset`은 저장 공간을 0으로 지우고 `memcpy`는 배열을 복사합니다.

| 파일 | 하는 일 |
|---|---|
| `src/bubble.h` | 상수, 구조체(`BBGame`, `BBPlayer` 등)와 함수 선언. 먼저 읽으면 나머지가 쉬워집니다. |
| `src/main.c` | 창 열기, 키보드·게임패드 입력 읽기, 이니셜 입력, 1/120초 간격 갱신 루프 |
| `src/game.c` | `bb_game_start`로 초기화하고 `bb_game_update`가 발판 → 플레이어 → 적·거품·바위·음식 → 접촉 판정 → 라운드 전환 순서로 처리 |
| `src/player.c` | 플레이어 이동·점프·거품 발사, 마나, 사망·부활, 거품·바위·음식과의 접촉. 음식 점수(300점)와 라운드 보너스(+500점)도 여기 있음 |
| `src/enemy.c` | ZenChan·Maita·Monsta의 움직임, 거품, 바위, 음식 |
| `src/level.c` | 다섯 라운드의 발판 좌표와 맵 만들기, 이동·생성·소멸하는 발판 |
| `src/world.c` | 벽·바닥과의 충돌 이동, 화면 크기에 맞춘 맵 확장·축소 |
| `src/score.c` | 순위표를 `fopen`·`fgets`·`sscanf`·`fprintf`로 읽고 씀 |
| `src/render.c` | PNG·소리 불러오기(`LoadTexture`, `LoadMusicStream`)와 글자·스프라이트 그리기 도구 |
| `src/scene.c` | 배경, 맵, 발판, 적, 거품, 음식, 플레이어, 라운드 전환 스크롤 그리기 |
| `src/ui.c` | 메뉴, 순위표, HUD, READY·보너스·일시정지 글자, 한 프레임 합치기(`bb_draw_game`) |

그림 파일은 모두 `Assets/`의 PNG이며 raylib으로 불러옵니다.

게임 로직에서 동적 메모리 할당은 하지 않습니다.
