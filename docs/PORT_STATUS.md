# 현재 상태

## 들어 있는 기능

- 1인 / 2인 협동, 다섯 라운드, 몬스터 3종(ZenChan, Maita, Monsta)과 바위 투척
- 거품 포획·터뜨리기, 음식 20종, 생명 5개·부활·무적, 2인 부활 버블(10초)
- 이동·생성·소멸하는 공중 발판(시작 위치·방향 무작위), 플레이어별 마나(이동 속도 2배)
- 라운드 배경은 `Backgrounds.png`(해·달·행성을 뺀 그림)이고, 1·4·5라운드의 해·달·행성은 `Celestial.png`에서 가운데 그림 자리에 한 번만 얹습니다. 벽과 바닥은 `Assets/LevelTiles.png`의 16×16 블록(라운드당 벽/윗면 2종)을 8×8 네 조각으로 나눠 그립니다.
- READY(시작 대기)·점수 화면은 1라운드 배경을 씁니다. 점수·마나(위)와 목숨·라운드(아래)는 맵 밖의 검은 띠에 그려서 맵을 가리지 않습니다.
- 화면 크기에 맞춰 넓어지는 맵, 전체 화면(F11)
- 상위 10개 순위표 (`Scores.txt`)
- 모든 음식은 300점. 한 라운드의 음식을 모두 먹으면 +500점이며, 화면에 `ALL FOOD BONUS!` 글자가 3초 동안 표시됩니다.
- 인트로(메뉴) 화면은 `Assets/IntroBackground.png`(로고가 들어 있는 256×224 그림)를 가운데 한 장만 쓰고, 창이 넓을 때 양옆은 로고·해를 뺀 `Assets/IntroSky.png`를 거울처럼 이어 붙입니다.
- 라운드가 끝나면 화면이 위로 스크롤되며 다음 라운드로 넘어갑니다. `ALL FOOD BONUS!` 글자가 다 보인 뒤에 스크롤이 시작됩니다.
- 플레이어는 죽으면 제자리에서 깜빡이고, 걷기는 2장·점프는 1장의 그림만 씁니다.
- 처치된 몬스터는 거품에서 날아가 벽·바닥에 최대 4번 튕긴 뒤(4초 제한) 과일이 되고, 12~15번 그림을 돌려 씁니다.

## 코드 구조

코드는 `src/`의 파일 11개입니다. 배열·구조체·포인터·파일 입출력·반복문·조건문 정도만 사용합니다.

| 파일 | 하는 일 |
|---|---|
| `bubble.h` | 상수, 구조체, 함수 선언 |
| `main.c` | 창 열기, 입력 읽기, 이니셜 입력, 메인 루프 |
| `game.c` | 게임 시작, 한 틱 갱신 순서, 라운드 전환 |
| `player.c` | 플레이어 이동·거품 발사·마나·사망/부활, 점수(300점·+500 보너스) |
| `enemy.c` | 몬스터 3종, 거품, 바위, 음식 |
| `level.c` | 라운드 지도, 이동·소멸하는 발판 |
| `world.c` | 벽·바닥 충돌 이동, 화면 크기에 맞춘 맵 확장 |
| `score.c` | 순위표 파일 읽기·쓰기 |
| `render.c` | 그림·소리 불러오기, 그리기 도구 |
| `scene.c` | 배경·맵·캐릭터·거품 그리기 |
| `ui.c` | HUD, 메뉴, 순위표 화면, 안내 글자 |

## 검증 범위

- `tests/`의 규칙 테스트 4개(게임 규칙, 라운드 지도, 화면 계산, 순위표)는 gcc로 빌드해 통과했습니다.
- 그림 파일(`Assets/`)은 이미지로 합성해 모양을 확인했습니다.
- 창을 띄우는 실제 실행(raylib 연결)은 개발 환경에서 확인하지 못했습니다. 직접 빌드해서 확인해 주세요.
- 게임패드 입력과 Windows 실행은 확인하지 않았습니다.
